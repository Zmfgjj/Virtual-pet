# Virtual Pet Companion

Aplikasi companion fantasy sederhana dengan fitur chat, voice interaction, dan kamera.

## Fitur
- **Home**: Menampilkan status mood dan tingkat pertemanan.
- **Chat**: Interaksi berbasis keyword dengan spirit.
- **Voice**: Speech-to-Text dan Text-to-Speech interaction.
- **Camera**: Fitur ambil foto dengan spirit.

## Setup untuk Kolaborator
1. Clone repository ini.
2. Tambahkan aset karakter (.png) ke `app/src/main/res/drawable/`.
3. Sync project dengan Gradle.
4. Pastikan device memiliki permission akses Microphone dan Camera.
